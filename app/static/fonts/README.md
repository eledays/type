# Material Symbols Rounded subset

`material-symbols-rounded-subset.woff2` is generated by the official Google
Fonts CSS API and contains only these ligatures:

`filter_alt`, `flag`, `info`, `local_fire_department`, `login`, `logout`, and
`search`.

Source request:

```text
https://fonts.googleapis.com/css2?family=Material+Symbols+Rounded&icon_names=filter_alt,flag,info,local_fire_department,login,logout,search&display=block
```

The `icon_names` values must remain alphabetically sorted. When adding an icon,
regenerate the subset, update the cache version in `index.css` and
`index.html`, and verify the resulting response is WOFF2. The icons are
licensed under Apache License 2.0; see `LICENSE-material-symbols.txt`.
