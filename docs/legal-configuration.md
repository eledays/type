# Настройка правовых документов

Правовые страницы не содержат реквизиты владельца в коде. При запуске Flask
подставляет значения из окружения. Перед публичным развёртыванием заполните
их в `.env.production`; локальная установка читает `.env`.

## Обязательные переменные

```dotenv
URL=https://type.example.ru/
LEGAL_OPERATOR_NAME=ИП Иванов Иван Иванович, ИНН 000000000000, ОГРНИП 000000000000000
LEGAL_OPERATOR_ADDRESS=000000, Россия, г. Москва, ул. Примерная, д. 1
LEGAL_CONTACT_EMAIL=privacy@example.ru
LEGAL_CONSENT_REQUIRED=true
```

- `URL` — точный публичный HTTPS-адрес сервиса со схемой и доменом. Он
  показывается в условиях использования, политике и согласии. Адрес должен
  совпадать с фактическим доменом; для production Compose домен берётся из
  `DOMAIN` и формирует `URL` автоматически.
- `LEGAL_OPERATOR_NAME` — полная публичная идентификация лица, которое
  определяет цели и способы обработки данных. Для организации укажите полное
  наименование, ИНН и ОГРН; для ИП — статус, ФИО, ИНН и ОГРНИП; для физлица —
  полное ФИО и при наличии идентифицирующие регистрационные сведения.
- `LEGAL_OPERATOR_ADDRESS` — полный адрес оператора, по которому можно
  направлять юридически значимые обращения: индекс, страна, регион, город,
  улица, дом и при необходимости офис/квартира.
- `LEGAL_CONTACT_EMAIL` — действующий контролируемый адрес для запросов о
  персональных данных, отзыва согласия и претензий. Не используйте личный
  ящик, если доступ к нему имеют посторонние.
- `LEGAL_CONSENT_REQUIRED` — оставьте `true` в публичной среде. Значение
  `false` предназначено только для специальных тестовых сценариев.

## Примеры имени оператора

Организация:

```dotenv
LEGAL_OPERATOR_NAME=ООО «Пример», ИНН 7700000000, ОГРН 1000000000000
```

Индивидуальный предприниматель:

```dotenv
LEGAL_OPERATOR_NAME=ИП Иванов Иван Иванович, ИНН 000000000000, ОГРНИП 000000000000000
```

Не копируйте примеры буквально. В документах должны быть реквизиты реального
оператора. После изменения текста любого документа обновите его версию в
`app/services/legal.py`: пользователи с прежней версией увидят запрос на
повторное согласие.

## Проверка перед запуском

1. Запустите `flask --app app db upgrade`.
2. Откройте `/legal/terms`, `/legal/privacy` и
   `/legal/personal-data-consent` и проверьте подставленные реквизиты.
3. Убедитесь, что ссылки ведут на фактический production-домен и рабочую
   почту.
4. Не коммитьте `.env` или `.env.production`: эти файлы могут содержать
   OAuth-секреты и другие закрытые настройки.
5. Перед публикацией согласуйте тексты и фактические процессы обработки с
   профильным юристом.
